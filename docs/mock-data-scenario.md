# 玉龙矿区数据场景 v2

基准时间：2026-09-12 09:00（北京时间），业务背景为8月14日至9月12日。地理位置沿用现有地图；运营单位、传感器数值、技术判断、费用及交易记录均为演示假设，不是实地运营资料或厂家参数。

## 内容

- 六台设备：每型号两台，01有关注事项，02为正常对照。设备履历包括序列号、投用日期、工时、班次、任务及保养日期。
- 每台三个指标、每10分钟采样、连续24小时，共435条遥测；总计2610条。温度或压力、负载、油耗分别绘制，不能混为一条曲线。
- 36份文档：每设备5份（履历、运行、工单、维修历史、检查卡），另6份矿区、调度、环境及商务资料。
- 18份独立案例：诊断6、复核3、需求3、跟进3、结案3。三条业务链对应散热维护、滤清系统检查与置换比较、液压检修。
- 其他矿区仅基础登记，设备及传感器数量未接入，不虚构成零故障或零设备。

`server/seed/scenario.mjs` 是内容与生成规则来源；`index.mjs` 维护设备、告警和基础资料。所有样本固定、可重复生成。报告的 evidenceSnapshot 保存正文快照；费用以整数分存储。生成与导出报告包含正文、证据及费用分项。

## 迁移

启动时检测 datasetVersion。旧数据文件先备份为同目录 `.pre-dataset-v2-时间戳.bak`，随后只补入未存在的 CASE 编号报告，保留旧报告版本、客户修改、请求记录。新数据集版本为2；再次启动不会重复导入。显式选择空数据重置后也不会重新填入。

已有旧报告仍保留原文；因此升级后的报告总数可能大于18。新建空白环境或选择完整演示重置时为18份。不要为了更新演示而删除 data 目录。

## 验收入口

全国总览 → 玉龙矿区 → Ops型号组 → 设备详情 → Operations → 资料库 / 商业报告。

资料库可按正文、来源、编号及标题检索。报告的 DOCUMENTS 展示证据快照，RELATED 可打开上游报告，OVERVIEW 展示处置与预算。正常机组无告警标红；01实例延续关联区域示意。

`npm test` 覆盖业务流程、金额合计、证据归属、时间顺序、五类报告、遥测稳定性及迁移备份与幂等性；`npm run build` 检查前端类型和打包。
