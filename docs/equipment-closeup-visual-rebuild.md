# 机械实例近景：参考图驱动的整体视觉重构方案

状态：待审阅。本文只定义下一轮重构，不代表已经实现。

参考图：[mine-ui.jpg](picture/mine-ui.jpg)

## 1. 重构目标与上一版的问题

点击矿区中的机械实例后，将视图转换为参考图所示的「机械作业空间与运行数据融合」场景。重构对象包含地形显示、机械构图、空间环带、设备标签、路线，以及覆盖在场景上的信息模块，不仅是 info2 的样式。

上一版仍然以两个纵向面板承载字段：左右有明显矩形背景、内容依靠长滚动展示、中央地图基本不变。因此即使修改字体颜色和分栏，也没有形成参考图的视觉重心与空间层次。下一版不沿用这套面板容器和信息排列。

必须保留的约束：

- Gotham 现有顶栏和工作区标签保留；不复制参考图的 logo、品牌区和顶端菜单，也不出现水印。
- 仅重构机械实例近景；全国与矿区俯瞰仍使用原来的界面。
- 进入近景隐藏 info1，不显示旧 info2，也不将二者换色后重新摆放。
- 使用中文业务名称、英文辅助标签，字体继续采用 MiSans。
- 复用现有三种机械模型、六个实例、三条路线和 mock 数据。
- 相机只在进入、切换实例、复位或返回等明确事件时移动，不持续跟随运动机械。

## 2. 参考图拆解与对应设计

| 参考图的视觉特征 | 本项目对应实现 | 不采用的旧形式 |
| --- | --- | --- |

参考图中的股票排行、PLCE、CPU/GPU 等装饰性字段不直接翻译；保留它们的密度、大小关系和图表位置，替换成机械业务中有对应数据的内容。不用虚构数值填满图表。

## 3. 桌面构图规格

以 1920 × 1080 为主验收尺寸，以下位置相对于 Gotham 顶栏以下的场景区域。

```text
┌──────────────── Gotham 原有顶栏及工作区标签 ────────────────┐
│ 返回矿区 / 玉龙矿区                        快照时间 · 演示数据 │
│                                                            │
│ 机械运行列表                           INSTANCE / TRUCK-01  │
│ 型号 · 实例 · 状态 · 工时               XDE240 / 矿卡          │
│ ─────────────────                      状态 · 工时 · 告警数   │
│                                                            │
│ 负载分析          地形轮廓 / 点阵           最近维护事件        │
│ 关键数值        ╭────────────────╮      日期 / 事项 / 状态     │
│ 正向柱图        │  半透明空间环带  │      ─────────────────   │
│                 │   选中机械      │      主要参数趋势         │
│ ─────────       ╰────────────────╯      数值 / 折线 / 时间轴  │
│ 燃油消耗              作业路线              ──────────────   │
│ 趋势图                                保养摘要 / 诊断入口   │
└────────────────────────────────────────────────────────────┘
```

- 左模块区：距左边约 3%，宽约 22%；右模块区：右边距约 3%，宽约 22%。中央约 50% 保持通透，避免覆盖机械。
- 两侧是各自独立的图表与文字块，不设贯穿整列的矩形底板。必要的可读性由场景两侧渐暗、文字阴影、图表局部 5%–10% 浅色底提供。
- 机械位于场景横向约 51%、纵向约 52% 的位置；机械本身占场景宽约 10%–14%，空间环带宽约 36%–44%。这是构图目标，需分别校准三种模型，而非固定套用 150 米相机距离。
- 顶部只保留简洁的返回与定位操作，取消近景下原有居中的矿区下拉框按钮组。全国、矿区俯瞰不受影响。
- 1920 × 1080 下核心内容一屏可见；1440 × 900 下通过减小间距、减少日志默认条数实现同样布局，不能把整列变成长滚动面板。
- 1280 宽度仍保留双侧布局，缩短标签、压缩非核心字段。更窄时采用设备摘要与可切换的数据模块，避免机械被两列挤没；小屏属于适配，不作为参考图复刻的主验收尺寸。

## 4. 中央场景效果：本轮核心工作

### 4.1 地形与机械的视觉分离

近景时将影像层调为低饱和、偏冷的暗灰色，保留山体纹理及道路。先使用影像层的亮度、饱和度、对比度参数，再配合两侧渐暗层。

不对整个 Canvas 直接使用灰度 CSS 滤镜，否则黄色机械和绿色环带也会失去颜色。退出近景必须恢复原影像参数，不能影响全国图与矿区图。

参考图的精细灰色矿坑与当前卫星影像、地形数据不是同一资产。首版复用现有地形，重点还原灰阶层次和空间构图；若实际地形精度不足，必须单独指出与参考图的差异，不能用高对比滤镜掩盖。是否制作独立矿坑地形属于后续资产决策，本轮不擅自替换地理场景。

### 4.2 绿色空间环带

以点击时机械位置为中心，建立局部坐标空间，生成以下四层：

1. 内层地面细环：柔和青绿色，标记选中区域。
2. 主环带：半透明绿色立体带，形成参考图中的空间高度和厚度，上沿略亮，下沿较暗。
3. 外部范围轮廓：非完美圆形的低透明灰白边界，与地形贴合。
4. 稀疏点阵：分布在外轮廓内部，增强参考图的空间测绘感，不覆盖机械表面。

初始调试半径可从 20 / 32 / 45 米开始，高度约 6–10 米，再结合模型尺寸与相机画面校准。这些数值只用于视觉调试，不是设备真实安全距离。

环带标注为「选中范围 / SELECTION AREA」，不宣称雷达、碰撞检测或实际安全边界。颜色不随故障变成整片红色；部件告警仍通过现有诊断能力表达。

使用 Cesium 的几何与材质绘制在世界空间，不使用固定在屏幕中心的 CSS 圆圈。地面部分采样地形，立体带沿采样后的边界构建，避免穿山或大面积悬空；点阵数量设置上限，避免每帧重建。

### 4.3 运动规则与相机

- 默认延续现有路线播放，不暂停六台机械的运动。
- 相机与选中范围固定在点击时的位置；机械继续沿路线移动。范围标签明确表示点击位置，避免用户误以为机械始终被范围约束。
- 设备名牌跟随机械世界坐标投影，但相机不跟随。
- 提供低调的「重新定位 / LOCATE」操作；点击后按机械当前位置重新构图、移动范围，属于一次新的相机事件。
- 切换到其他实例时，取消上一次相机飞行和未完成的范围采样；使用新实例的当前位置更新构图。
- 点击地形空白不退出详情，避免误触；返回矿区、返回全国才明确退出。

### 4.4 路线与标签

弱化当前贯穿屏幕的高亮青色粗路线。选中实例所属路线显示为细灰白线或低亮青绿线，其他路线降低透明度；不改变原路线坐标与发车逻辑。

近景隐藏蓝色圆形拾取标记的可见外观，保留模型拾取和适当的不可见点击容差。选中实例显示细框双语名牌；未选中实例只在 hover 时显示完整名称，避免增加重叠。

## 5. 信息模块与实际数据映射

| 区域 | 展示内容 | 数据来源与规则 |
| --- | --- | --- |
| 左上机械列表 | 同矿区六个实例、型号、中文状态、工时；选中行浅底突出 | BusinessProvider 中的 equipment；点击行切换实例并触发一次定位 |
| 左中负载分析 | 最新发动机负载、大号百分比、近 24 小时正向柱图 | telemetry 的发动机负载字段；按小时聚合，不使用参考图的镜像负柱假装负载可以为负 |
| 左下燃油消耗 | 最新值、单位、简洁趋势 | telemetry 的燃油消耗字段；只绘制已有时间样本 |
| 右上实例身份 | TRUCK-01 等实例 ID、大号型号、机械类别、运行状态、累计工时、告警数 | equipment 与 alerts；状态使用中文，英文为小标签 |
| 右中维护事件 | 日期、事件名称、展开详情入口；默认最近 3 条 | work-orders 按日期倒序；没有数据时明确空态 |
| 右下主要遥测 | 当前值、单位、带网格与时间刻度的趋势图 | 矿卡：冷却液温度；挖掘机：滤清器压差；铲车：主泵压力 |
| 右下摘要与动作 | 下次保养、最新诊断简述、进入设备诊断 | equipment.nextServiceAt 与最新 diagnosis；诊断动作沿用现有工作区跳转 |
| 顶部辅助信息 | 玉龙矿区、数据快照时间、演示数据标记 | equipment / telemetry 的真实快照时间，不用系统当前时间冒充实时数据 |

序列号、客户、投用时间等低频字段放入右上身份区的「档案详情」展开层，默认不占据一整列。不再将所有关联字段、工单正文和报告摘要串成纵向长档案。

图表必须具有字段名、单位、时间范围和可理解的刻度。不能简单沿用当前无刻度的小波形后拉大，也不复制参考图中的无业务含义仪表。无遥测、无告警、接口失败分别提供空态或重试状态。

## 6. 视觉规格与动效

| 项目 | 规格方向 |
| --- | --- |
| 底色 | 黑灰、冷灰地形；保留局部道路层次 |
| 主色 | 绿色空间带，图表使用青绿；机械黄色是场景的实体焦点 |
| 文字 | 主信息灰白，次级文字低饱和灰；中文优先，英文大写作为辅助 |
| 字号 | 实例/型号 32–42px；关键指标 28–36px；模块标题 13–15px；列表 11–12px；英文标签 9–10px |
| 分区 | 1px 灰白细线、短高亮线段、极浅条带；不用大圆角卡片、重阴影与完整边框 |
| 告警 | 小面积琥珀色或红色，只用于告警文字和标记 |
| 入场 | 相机开始缩进时旧面板退出；构图稳定后数据模块在约 200–300ms 内淡入，环带短暂显现 |
| 持续动画 | 默认无强扫描、无不断跳动随机数字、无持续旋转；真实数据变化时更新图表 |
| 减少动态效果 | 遵守 prefers-reduced-motion，缩短或取消非必要过渡 |

## 7. 实现结构与状态管理

建议新建独立近景组件，替换本轮新增的 equipment-hud，而不是继续往 ScenePanels.tsx 与全局 CSS 中追加覆盖规则。

| 文件/模块 | 计划职责 |
| --- | --- |
| `src/components/EquipmentCloseup/` | 独立页面组合、机械列表、身份摘要、维护事件、遥测图表 |
| `src/components/EquipmentCloseup/equipment-closeup.css` | 仅限近景的布局与视觉，移除上一版 HUD 专属样式 |
| `src/cesium/equipment-focus-effects.js` | 环带、边界、点阵、标签、影像参数切换及清理 |
| `src/cesium/scene-navigation.js` | 按型号尺寸和窗口比例计算一次性设备构图 |
| `src/components/CesiumViewer.tsx` | 向外同步相机阶段、近景效果生命周期、拾取和路线显示 |
| `src/components/GlobalOverview.tsx` | 统一管理矿区/设备模式与返回操作，挂载新近景组件 |
| 现有 telemetry、alerts、work-orders 接口 | 复用，无需为了此次视觉重构新增后端 |

当前代码中需要一并处理的状态问题：

- 相机阶段目前仅存在 CesiumViewer 内部，应通知近景 UI，避免地形仍在加载时面板已经假装定位完成。
- 当前点击空白会清除设备 ID；近景应改为保持选中，退出使用明确按钮。
- 当前 ResizeObserver 调用矿区 navigate，可能让相机返回矿区但设备面板仍在。重构时按当前模式调整构图，并作为明确的窗口适配事件处理。
- 返回矿区、全国、切换工作区及组件卸载时，恢复影像参数、路线、拾取标记并清理事件与 Cesium 对象。
- 快速切换实例时取消过期请求和地形采样结果，不能出现上一台机械的告警或范围。

## 8. 实施顺序

1. **先做中央场景样板**：只选 XDE240，完成灰阶地形、机械比例、环带、点阵和路线弱化。先截图与参考图对比，中央场景不达标不继续堆信息。
2. **重建整页构图**：删除上一版长面板容器，按参考图摆放独立信息模块，接入真实 mock 字段与带刻度图表。
3. **扩展三种型号**：校准矿卡、挖掘机、铲车的相机距离和环带比例，支持六实例切换。
4. **整合状态与返回**：验证相机不跟随、重新定位、加载、失败、退出、窗口变化和工作区切换。
5. **视觉验收**：在地形及机械完整加载后截图，不再以黑色加载背景上的面板截图作为完成证据。

## 9. 验收标准

视觉验收必须与参考图并排检查：

- [ ] 第一眼的主体是灰色矿区、黄色机械和绿色立体环带，具有参考图的空间层次。
- [ ] 不出现上一版两张高大的矩形侧面板；两侧是直接叠加于场景的独立模块。
- [ ] 不出现旧 info1、旧 info2、参考图 logo、日文或水印。
- [ ] 左上列表、左侧柱图、右上身份区、右侧日志与趋势的位置和密度接近参考图。
- [ ] 1920 × 1080 与 1440 × 900 下核心信息一屏可见，中央机械不被文字覆盖。
- [ ] 地形已加载，环带不明显穿地，路线不抢视觉，模型颜色未被整体灰度处理。
- [ ] 三种机械均有完整截图，不能只验证其中一种。

功能验收：

- [ ] 切换实例时更新数据、名牌、范围和一次性构图；机械运动时相机保持不动。
- [ ] 重新定位有效，点击空白不误退，返回矿区恢复 info1 与原地图视觉。
- [ ] 图表单位、时间、字段与接口一致；不存在伪造传感器、安全范围或实时性描述。
- [ ] 设备诊断入口可用，加载失败可重试，快速切换不串数据。
- [ ] 连续进入退出不累积实体、事件和点阵；绘制对象数量受控。
