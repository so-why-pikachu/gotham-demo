# 玉龙矿区演示车队

共六个实例，每种型号两台。原实例、报告及历史状态保留，新增实例拥有独立 ID、工时、证据记录和正常运行状态；可独立发起诊断。

| 实例 | 路线 | 出发（秒） | 停靠点 |
| --- | --- | --- | --- |
| truck-01 | 主运输线 | 0 | P6 |
| excavator-01 | 主运输线 | 12 | P5 |
| loader-01 | 主运输线 | 24 | P4 |
| truck-02 | 东侧作业线 | 6 | E5 |
| excavator-02 | 东侧作业线 | 18 | E4 |
| loader-02 | 南侧作业线 | 30 | S5 |

两条新增线路为演示路径，未经现场道路核验；使用与原线路相同的地形采样、姿态处理和速度。路径坐标位于 `src/cesium/route/waypoints.js`，车辆分配位于 `fleet.js`。等待车辆在出发时出现，抵达后停留；全国视角隐藏所有路线、模型及点位。矿区预设镜头扩大以容纳三条路径。

`npm run test:fleet` 使用真实 Cesium 和模拟坡度检查六车全程间距、出发时间、终点与转弯。该检查验证演示运动逻辑，不验证现实道路可通行性。
