# Mock 后端接入记录

后端入口 `server/index.mjs` 使用 Node 内置 HTTP 模块。默认只监听 127.0.0.1:5182。`server/routes.mjs` 实现实施方案中的 `/api/v1` 接口；种子与业务规则分别位于 `server/seed/`、`server/domain/`。无需新增依赖。

## 已实现

- 三辆当前模型设备的矿区、客户、告警、遥测、维修史和知识文档关联。
- 诊断与证据复核、稳定报告 ID 和版本、商机派生、需求报告金额计算。
- 客户分类、报告筛选和分页、精确版本查询、Markdown 导出、仅本地记录的模拟推送。
- 默认三份种子诊断；总览中可确认重置为预置或零报告。刷新和服务重启不自动重置。
- 串行事务和 JSON 文件原子替换；落盘失败不提交内存状态；损坏文件不静默清空。
- HTTP 400/404/409、业务请求幂等、输入校验；每个 JSON 响应携带 mock 标记。

## 前端保持与适配

保留 Gotham 顶部导航、四类工作区及主体布局。地图只追加模型拾取后打开 Operations 的回调，三车路线代码未改动。

Operations 的现有 Inspector 追加证据、诊断、复核和需求草稿，中央原有二维占位区域保留。Archive 改为服务端文档及关联设备跳转。

商业报告继续使用同源 iframe、原三维场景和模型查看器。父页面负责 API 请求，通过校验来源窗口和协议版本的消息桥提供报告快照、版本及动作结果。背景仍为 288 个模型实例，标签写 ARCHIVE；被选报告显示实际编号。背景重复实例映射同一真实报告，不计为额外报告。

五列为诊断、复核、需求、模拟跟进、预留档案。计数来自实际数据；空列无可打开报告。底部每组最多显示 8 个选择刻度，方向键可继续浏览其他组。收藏按报告 ID 保存，业务版本由服务端提供。

API 数据保存在 BusinessProvider 上方，工作区切换不会丢失业务缓存；失败时保留原数据并显示重试。局部设备查询在组件卸载或切换对象时取消。报告业务不另写浏览器业务数据库。

## 使用和测试

启动、端口和演示路径见根 README。API 测试使用临时文件；浏览器测试自行启动独立临时 API，实际 `data/demo-state.json` 不受测试重置影响。

自动化结果保存在 `docs/business-verification/checks.json`；生成的截图已清理，可运行 `npm run test:reports` 重新生成。运动测试仍使用合成地形高度；本轮浏览器环境无法正常加载在线地图资源，未把在线地形或 Cesium ion 连通性算作通过项。保留原地图联网要求。

本轮结果：类型检查与双入口构建通过；2 组服务端集成测试通过，涵盖 HTTP 业务、错误输入、幂等、重启持久化和写入失败恢复；9 组浏览器流程通过，运行时异常和本地资源请求失败均为 0。三车专项测试通过。统一 dev 的启动、API 代理和退出后一并释放 5181/5182 端口已验证。

当前预览运行于 `http://127.0.0.1:5181`（WEB_PORT=5181），API 位于 5182。后续启动默认前端端口仍为 5180，可按 README 覆盖。

报告与工况均为适配到三车的预置案例，不是型号真实参数或维修建议。模拟推送不会发送消息。当前只支持本机 Demo，不增加生产鉴权、数据库或真正的 AI 服务。
